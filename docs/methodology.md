# 방법론과 보존 규칙

이 문서는 기존 Gate의 구현을 설명한다. 새로운 연구설계 또는 결과를 제안하지 않는다. 상세 동결 문서는 frozen/에 보존했다.

## 데이터와 월 적격성

원자료 ZIP의 이름 대신 실제 기준_날짜를 읽는다. 스키마, ID, 순서, 0/빈칸, 완전중복과 동일 키 충돌을 구분한다. 완전 동일 관측은 하나만 남기고 충돌 관측은 날짜/키 수준에서 보류한다. 2026-06-30의 51개 충돌 키 때문에 6월 전체를 제외하지 않는다.

평상 평일은 동결 공식 달력의 월~금 중 휴일 제외일이다. 계획일 N에 대해 common_days >= ceil(0.90*N) 및 common_days >= L, L=max(16,ceil(16*N/19))를 적용한다. 주별 원자료 가용성과 Core 반복조건을 구분하며 주별 최소는 min(3,계획 평상 평일 수)다. 없는 날짜를 0, 보간값, 다른 날짜 복제값으로 채우지 않는다.

## 역사 마스터와 공간

월 시작일 이하의 가장 최근 공식 스냅샷을 월 전체에 고정한다. 매핑은 202509→20250901, 202510→20250901, 202511→20251002, 202512→20251103, 202601→20251209, 202602→20260108, 202603→20260226, 202604→20260305, 202605→20260402, 202606→20260506, 202607→20260701, 202608→20260701이다.

노선유형은 같은 역사 기준정보의 정확한 노선명/ID 연결을 사용한다. 간선, 지선, 순환, 광역, 마을을 포함하며 미확인 유형과 Main 비허용 유형을 제외한다. 최신 유형이나 정류장 좌표를 과거에 소급하지 않는다. 좌표 결측을 서울 밖으로 바꾸지 않는다. 큰 좌표 변화만으로 최신 좌표를 선택하지 않고 동결된 개별 좌표 보류를 유지한다.

기존 427개 경계와 코드 체계를 사용한다. 원 ZIP에 PRJ가 없다는 사실과 기존 검증 EPSG:5179를 그대로 기록했다. 좌표 투영과 포함 판정은 F0M이 승계한 VTK 투영, matplotlib Path 기반 함수 그대로다. Strict Core는 양 끝점이 모두 서울 내부인 구간이며 도착 정류장 행정동에 귀속한다.

## C2와 U

노선/출발/도착 NODE/출발순서/도착순서/시간의 양수 운행시간 관측만 사용한다. 관측일 L 및 주별 반복조건을 통과한 세부키에서 기존 선형 분위수 P50과 P90을 구해 U=P90−P50으로 계산한다. 행정동 U는 Strict Core의 기존 노선-구간-시간 관측 U 중앙값이다. 2→3 구간은 모든 월 Main에서 제외한다.

C2의 연결 정류장 모집단은 기존 시간 Core의 양 끝점과 역사 마스터에 의해 정해진다. 같은 노선/NODE의 반복 순서가 있으면 날짜/시간 내 관측 부분합을 먼저 만들고, 날짜 중앙값을 노선-정류장-시간 대표값으로 사용한다. 시간을 합하고 노선을 합한 후 정류장별 관측 서비스량의 동내 중앙값을 구한다. min_count와 빈칸 처리는 원본 코드와 동일하다. 새로운 16일 공급 필터는 없다.

순위용 복사본의 round(8), 평균동률 순위와 비결측 분모를 유지한다. 월별 두 백분위 >=75 교집합은 탐색기준이며 정책 임계값이 아니다.

## 반복성과 강건성

기준 8개월, 8월 포함 보조 9개월, 1월 제외 7개월을 분리한다. V는 두 지표 평가가능 월 수, K는 그 안의 후보 월 수, R=K/V다. held 월을 반복분모에 넣지 않는다. K=8의 9개 지역을 그대로 보존하며 새로운 지속 cutoff를 만들지 않는다.

IQR, 엄격 관측조건, 동일 정류장쌍 중복완화, AM 07~09, PM 17~19, 첫 월요일부터 28일의 4주창은 기존 F1C 코드대로다. 엄격 조건과 4주창의 가용월 수를 숨기지 않는다. 1월은 Main을 유지하고 월 전체 제외를 QA로 남긴다.

## 미시 진단

M1은 9개 동의 저장 Core U를 사용한다. 월별 서울 전체 Strict 시간대 U 분포의 평균동률 백분위 >=75를 동일 기준으로 대조한다. A는 노선/NODE 쌍이며 복수 순서키를 같은 시간에서 중앙값으로 접고 시간 중앙값으로 월 A를 요약한다. B는 같은 정류장쌍의 월 A 중앙값이다. 백분위 대조에서 M1이 사용한 고정 보간을 그대로 보존한다. 43개는 각 동의 K 최댓값 동률 전체다.

M2는 각 시간의 V_h, K_h, R_h 및 U 중앙값을 별도로 보존한다. 일별 패널은 저장 P50/P90/U 및 양수 관측일, 원본 해시와 대조한 셀만 사용한다. 요일 진단은 같은 월과 같은 세부키의 E/I로 기준화하고 동결 공통 지지표본 및 동일가중 순서를 유지한다.

M3는 정류장쌍 공유노선 수와 복수노선의 동반 패턴을 기술한다. B에 진단노선 자체가 포함된 기존 비교이며 다른 노선만을 남긴 독립 검증이 아니다. 단일노선의 기계적 일치를 공통환경 증거로 쓰지 않는다. 실제 역사적 경로를 검증하지 못한 도로속도/교차로/전용차로는 held_geometry다.

## Gate 4 일별 사례

생활인구는 동일 성분/동/월/요일/시간의 기존 기준 중앙값 대비 상대편차다. 기준값 0 또는 결측이면 상대편차는 NA다. 세 성분을 합산하지 않는다. 승인 6개 동에서 24시간 가용 상대편차 중앙값을 날짜 노출로 사용한다.

M2의 E와 I는 같은 A/날짜/시간의 복수 순서키를 E 중앙값/I 평균으로 접은 후, A/날짜에서 시간 E 중앙값/I 평균, 동/날짜에서 구간 E 중앙값/I 평균을 적용한다. I는 기존 C2B처럼 내부 정확 유리수로 평균해 동률의 부동소수점 오류를 막는다. 음수 E와 0을 보존한다.

Spearman은 각 동 내 날짜 완전쌍으로 계산하고 월별, pooled, 1월 전체 제외를 모두 보존한다. 기상은 서울 ASOS 108 공식 일자료만 일별로 붙인다. 시간 강수 합산이나 AWS 공간배정을 Main으로 사용하지 않는다. 숫자 0/양수/비수치 NA를 구분하며 강수 비교는 자료범위가 제한된 조건부 결과다.

대표 3개 C3 사례는 공식 기록의 현실 맥락 검토다. 행사일과 버스 결과를 새로 통계결합하거나 특정 행사를 원인으로 확정하지 않았다.
