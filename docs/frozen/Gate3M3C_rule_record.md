# Gate 3-M3C 계산 전 구현규칙

고정 43개 및 이를 포함한 758개를 유지한다. Main은 202509,202510,202601,202602,202603,202604,202605,202606이다. 202608은 Main 산출에서 제외한다. held_date 세 달은 NA다. 다음 규칙은 M3C 수치 산출 전에 기록한다.

1. 월별 관계는 M1 저장 노선-구간 월 U와 M3B 같은 월 shared_route_count가 모두 있는 758개 배경의 관측을 사용한다. Spearman은 평균 동률 순위의 Pearson으로 계산한다. 월별 값의 중앙값/최솟값/최댓값을 요약하고 유의성 검정은 하지 않는다. 43개만의 상관은 계산하지 않는다.
2. 노선 수 수준별 표는 실제 정수값을 그대로 사용한다. U의 P25/P75는 선형 보간 표본 분위수다. 기존 M1 월 고불안정 flag가 있는 관측만 비율 분모에 넣고 flag 유효 n도 적는다. 전체 Main 표는 유효 구간-월 관측의 풀링이며 서로 독립된 구간 수나 월 균등 가중치가 아니다.
3. pair_support는 M2 저장 A-B 비교 중 Main, 고정 43개, A/B 유효, **동일 월/동일 시각의 n_routes>=2**인 비교만 사용한다. 월 합집합 공유노선 수가 2 이상인 것만으로 시각별 복수노선 조건을 대신하지 않는다. A 고불안정일 때의 both_high 및 A_only_high를 세며 분모 0이면 비율은 NA다. 단일노선 시간 비교는 분리해 공개한다.
4. B는 A도 포함한다. 기존 B를 바꾸거나 새로운 leave-one-out U/백분위를 만들지 않는다. 공식 지표의 해석 목적은 '해당 노선의 고불안정이 같은 정류장쌍의 다른 노선에서도 함께 관측된 정도'의 점검이다. B 자기포함 때문에 B flag만으로 다른 노선의 동시 고불안정을 확정할 수 없어, 기존 758개 A의 동일 월/시간 flag에서 실제 다른 노선 고불안정 건수 및 동시 여부를 별도 확인한다. 새 cutoff나 새 고불안정 flag는 없다.
5. 시간패턴은 M2 저장 R_h 및 최고 시간, AM-PM 공통월 비교, 요일 요약을 연결한다. 시간대 R 중앙값은 V_h>0인 기존 R_h들의 단순 중앙값으로 요약하며 별도 합성점수로 쓰지 않는다. 요일값을 전일로 새로 합치지 않고 기존 시간대별 요일 요약의 최대 요일 건수와 지지표본을 보존한다.
6. 승하차 A35만 각 끝점/승차하차별 24개 원 시간 라벨을 더한다. 24개 모두 있어야 월합계를 기록한다. 네 합계를 서로 더하지 않는다. B/C 8개는 NA다. 명칭은 '2026년 6월 승하차 이벤트 맥락'이다. 시간대 U와 승하차의 상관은 계산하지 않는다.
7. 사례선정의 공유노선 수 극단은 증거행렬의 **Main 월 shared_route_count 중앙값**의 최댓값/최솟값이다. 변화 범위도 함께 제시한다. pair_support 극단은 복수노선 A 고불안정 비교 분모가 양수인 경우만 대상으로, 분자/분모의 정확한 분수로 동률을 비교한다. 분모에 추가 최소값 cutoff를 만들지 않는다.
8. 시간대 최고 R 범위의 폭은 M2가 이미 보존한 **최고 R 동률 시간대 개수**로 정의한다. 시각의 최솟값과 최댓값의 차이를 연속 폭으로 해석하지 않는다. 여섯 극단 각각의 동률을 전부 보존하고, 중복 구간의 선정 사유를 모두 기록한다. 표시번호는 기존 명단 식별자다.
9. 도로속도, 교차로, 전용차로는 모두 held_geometry다. 역사 경로를 추가로 받거나 공간자료를 사후 결합하지 않는다. 연속값과 실제 건수를 제시하며 원인유형, 정책 우선순위, 새 분석 구간은 정하지 않는다.
