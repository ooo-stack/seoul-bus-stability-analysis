# Gate 2-F0D 시간단위 동결

설계 버전 F0D-1.0 / 동결일 2026-10-07 / 연구기간 2025-09-01~2026-08-31 / 시간대 Asia/Seoul.

**Main은 달력월이다.** 매월 1일부터 말일까지의 계획 평상 평일을 정의하고, 그중 운행시간과 운행횟수 원자료가 함께 존재하는 날짜를 공통 분석일로 사용한다. 자료 누락이 있는 달은 달력월 전체가 완전 관측되었다고 표현하지 않는다. ZIP의 월 이름은 기간을 결정하지 않는다.

월간 승하차는 달력월 전체 이벤트이며 Main 버스지표는 평상 평일이다. 달력월을 택해도 두 자료의 실제 날짜, 노선 모집단과 사람 단위가 같아지는 것은 아니다. 이 Gate에서는 외부자료를 읽거나 결합하지 않는다.

## 고정창 강건성

다른 시간단위는 **사전 지정 강건성 한 가지**로 남긴다. 각 기준월의 첫 월요일 00시부터 27일 뒤 일요일까지 28일이다. 첫 월요일이 휴일이어도 창을 옮기지 않는다. 월경계 밖 날짜도 이 창에 속하면 포함한다. 가장 완전한 창이나 후보가 많이 반복되는 창을 찾지 않는다. 시작일 이동, 누락일 대체, 여러 창 중 선택을 금지한다.

창끼리 겹치지 않으나 기준월의 모든 날짜를 덮지는 않는다. 4주 창 안의 공휴일도 제외하며, 달력월과 같은 계획일 분모, 90% 공통일 조건, 최소 양수일과 주별 조건을 사용한다. 2026년 7월 고정창도 7월 17일 공휴일을 제외하므로 계획 평상 평일은 19일이다. F0S의 '날짜 누락' 진단을 수정한 것이 아니라 날짜의 분석상 역할을 구분한 것이다.

고정창 자료요건 미충족은 강건성 계산 불가로 남긴다. Main을 고정창으로 교체하거나 Main에서 보류된 월을 고정창 결과로 대체하지 않는다. 창별 유효 여부와 분모를 별도로 보존한다. 4주와 달력월은 대부분의 날짜가 겹치므로 독립 검증이 아니다.

## 8월 이력

기존 8월 결과는 2026-08-03~08-30의 19개 평상 평일에서 개발되었다. 새 Main의 8월은 08-01~08-31이며 계획 평상 평일 20일이다. 새 8월 값이 기존 값과 같아야 한다는 제약은 없다. 기존 결과는 원형으로 보존하고 새 결과는 다른 기간과 마스터 규칙의 버전으로 표기한다.

고정창 8월은 기존 기간과 같아 기간 비교의 기준이 된다. 그러나 새 역사 마스터 규칙까지 적용하면 기존 표본과 자동으로 동일하지 않다. 기존 파이프라인의 정확한 복제와 새 규칙의 8월 강건성 결과를 구분한다.

주 분석의 시간적 재현성 보고는 2025-09~2026-07의 유효 월을 중심으로 한다. 2026-08을 포함한 전체 12개월 요약은 별도 기술 요약이다. 모두 포함할 수 있을 것이라고 미리 보장하지 않는다.
