# Gate 4-C2B 실행명세

사용자 명세를 최상위로 적용한다. Main 8개월과 고정 43개 구간을 변경하지 않는다. C2A-R 공간 승인 6개 동에서만 생활인구를 연결한다. AWS는 사용하지 않는다. 외부자료와 버스의 시간단위 직접 결합을 수행하지 않는다.

## 일별 집계

M2 복원 패널의 valid=True, QA_status=pass, strict_core=True, common_planned=True인 양수 관측만 기존 E_sec 및 P90_reached를 그대로 이용한다. 기존 P50/P90/U를 새로 추정하지 않는다. 같은 A(노선/NODE 쌍)의 동일 날짜/시간에 원 순서키가 복수이면, M2의 순서키 접기 원칙을 승계하여 E는 중앙값, I는 평균으로 먼저 한 시간 셀에 접는다. 원 순서별 관측 수와 접힌 시간 셀 수를 구분한다.

시간 셀에서 A-날짜의 E 중앙값, I 평균을 계산한 뒤, 동-날짜의 E는 고정 구간 일별 E 중앙값, I는 구간 일별 I 평균으로 집계한다. 관측이 없는 고정 구간의 결과는 NA이며, 가용 구간에 동일 가중한다. 고정 구간 수, 유효 구간 수와 시간 셀 수를 함께 보존한다. 관측 수에 따른 새로운 제외기준을 만들지 않는다. 모든 계획 평상 평일의 9개 동 격자를 보존한다.

생활인구는 C2A에서 이미 계산된 성분별 relative_activity_deviation의 24시간 라벨 중앙값이다. 결측은 보간하지 않고 가용 시간 수를 기록한다. 세 성분을 각각 분석하며 합산하지 않는다. 기준화 산식이나 기준월을 변경하지 않는다.

## 외부조건 비교

같은 동과 날짜의 완전쌍만 각 통계에 사용한다. 세 생활인구 성분 각각, 2개 버스 결과 각각의 월별 Spearman과 날짜 풀링 Main, 1월 전체 제외를 모두 계산한다. 적어도 2개 완전쌍과 양 변수의 변이가 있어야 Spearman을 정의하며 그 외는 NA다. 검정, p값, 새 cutoff, 결과별 표본 최적화는 하지 않는다.

기상은 ASOS 서울 108의 공식 일강수량과 공식 일평균기온을 우선한다. 공식 일자료를 확보하지 못하면 해당 비교를 held_official_daily_weather로 보류하고 NA로 기록한다. 시간자료 강수 합산 또는 자체 일평균기온으로 대체하지 않는다. 일강수량 명시 숫자 0은 dry_day, 양수는 rain_day, 공백 또는 미확인 표기는 NA다. 건조/강수 양쪽의 날짜가 있어야 차이를 계산한다. 평균과 중앙값 차이는 rain minus dry이며 I 차이는 비율과 퍼센트포인트를 구분한다. 모든 월별 결과, 날짜 pooled와 1월 전체 제외를 보존한다.

방향 반복성은 월별 양수/0/음수/NA 개수와 실제 계수의 범위 및 중앙값으로 공개한다. 반복을 판정하는 새 이분형 cutoff 또는 원인유형은 만들지 않는다. 동-날짜가 해석 단위다. 같은 날 9개 동이 같은 서울 기상값을 공유함을 공개한다. pooled는 관측 날짜 동일 가중이며 월 동일 가중 결과라고 부르지 않는다. 계절, 요일, 미측정 활동과 표본구성의 교란을 통제했다는 주장을 하지 않는다.

1월은 Main에 포함하고 1월 전체 제외만 QA로 제공한다. held 월과 8월은 포함하지 않는다. 약한 결과와 반대 방향도 모두 공개하며, 자료 미확보와 관측된 약한 관계를 구별한다.
