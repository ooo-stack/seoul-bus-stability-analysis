# Gate 2-F0D 다개월 반복분석 설계 동결

작업일: 2026-10-07 / 버전: F0D-1.0 / 대상: 2025-09~2026-08.

**달력월을 Main으로 확정한다. 기존 P90-P50, C2와 두 지표의 월별 상위 25% 탐색규칙을 유지하며, 자료 누락과 역사 마스터 문제를 처리하는 공통 규칙을 동결한다. Gate 2-F1의 입력 및 구조 점검은 진행 가능하지만, 12개월 Core 결과를 즉시 일괄 계산할 수 있다고 판정하지 않는다.**

## 1. 작업 범위와 증거 상태

필수 기존 보고서 7개를 읽고 설계 이유와 제한을 확인했다. 월별 운행시간 또는 서비스량, 상관, 후보, 반복률과 정책결론은 계산하지 않았다. 최근 업로드한 버스 및 공간과 외부수요 자료는 열지 않았다. 실제 자료가 있는 평일 수나 적격월 수도 새로 계산하지 않았다. 공식 공휴일 자료 확인과 달력 기반 계획일수 및 동결식의 정수 하한 계산만 수행했다.

F0S의 B 판정은 일부 공통 처리규칙 아래 확장 가능하다는 조건부 판단이다. 스키마 유지가 12개월의 완전성이나 역사 마스터 적격을 자동 보증하지 않는다. 이미 8월 분석과 일부 시점의 구조 진단을 본 상태임을 공개한다. 이번 문서는 나머지 월의 연구결과 계산 전 사전동결이며 과거 8월 연구가 사전등록되었다는 주장이나 공개 등록기관의 등록 증명이 아니다.

## 4. 공휴일에서 확인한 변경

우주항공청의 2026-06-29 공식 발표는 노동절과 제헌절이 2026년부터 공휴일로 적용됐음을 명시한다. 따라서 2026-05-01과 2026-07-17은 평상 평일에서 제외한다. 전국동시지방선거 2026-06-03은 정식 2026년 월력요항 첨부의 국경일과 공휴일 표로 확인했다. 최초 2026년 발표나 공식 발표 전 달력자료만 복사하면 날짜 분모를 잘못 정할 수 있다.

F0S에서 7월17일 횟수 원자료가 없다는 진단은 그대로 유지한다. 그 날짜가 공휴일이라는 별도 사실에 따라 평상 평일 분모에서는 제외할 뿐, 원자료가 복원되었다고 주장하지 않는다. 다른 누락일도 공식 휴일인지와 실제 부재인지를 별도로 기록한다. 자세한 날짜표와 근거는 `eligible_day_rule.md`에 있다.

## 6. 후보 반복성과 외부검증의 범위

월별 후보 여부는 True, False, NA의 세 상태다. 유효월 중 후보개월 K와 평가가능월 V 및 K/V를 함께 보고한다. 0회부터 가능한 최대 유효월 수까지의 전체 분포를 공개하고, V=0인 동은 0회와 분리한다. '몇 개월 이상 최종 후보'라는 기준을 만들지 않는다. 상단 교집합의 반복만으로 서비스량이 비슷한 모든 지역의 차이를 입증하지 않도록 전체 산점도와 기존 연속 비교도 같이 보고하도록 명세를 고정했다.

생활이동, 승하차와 전용차로는 이번에 확대하지 않는다. 다개월 Core 이후 별도 Gate에서 외부자료 범위를 판단한다. 기존13개 정책검토 후보를 다개월 선정의 정답이나 목표 개수로 사용하지 않는다.

## 7. 변경관리

1. F0D-1.0 문서와 decision_log.csv를 결과 계산 전 보존하고 해시를 기록한다.
2. 공식 휴일, 공급자 정정, 누락 원본의 추가 확보는 입력 버전 변경이다. 같은 동결식으로 모든 영향월을 다시 처리한다.
3. 분석단위, 분모, 임계조건, 마스터 원칙이나 지표 산식을 바꾸는 것은 설계 변경이다. 기존 버전을 덮어쓰지 말고 새 버전, 이유, 결과 열람 여부와 적용범위를 명시한다.
4. 특정 월의 원하는 결과를 얻으려는 예외를 허용하지 않는다. 정정 전후 차이를 숨기거나 좋은 버전만 최종 보고하지 않는다.
5. 구현오류 수정도 영향월 전체에 적용하고 이전결과와 산출물 계보를 보존한다.
