# Gate 2-F0D 평상 평일과 반복관측 조건

설계 버전 F0D-1.0. 아래 숫자는 연구자의 사전 품질관리 선택이며 공식 정책 임계값이나 통계적 정밀도 보증이 아니다.

## 1. 평상 평일

Asia/Seoul의 월요일~금요일 중 서울에 적용되는 공식 공휴일, 대체공휴일, 임시공휴일 및 법정 선거일을 제외한다. 실제 해당 날짜에 시행된 법정 상태를 사용한다. 최초 월력요항 이후 공식 지정 변경은 근거와 적용일을 기록하여 반영한다. 주말은 제외한다. 평일인 명절 전날, 샌드위치 날, 방학, 휴가철, 강우일, 수능일 등은 법정 휴일이라는 근거가 없으면 임의로 빼지 않는다.

계획일 집합 P_m은 자료 존재 여부나 운행시간 값과 무관하게 먼저 확정한다. 계획일은 달력상 관측 기회이며 모든 노선의 공식 운행 예정일을 뜻하지 않는다.

## 2. 원자료 부재와 휴일 분리

T_m = 계획일 중 읽을 수 있고 스키마를 통과한 운행시간 일자 자료가 존재하는 날.

F_m = 계획일 중 같은 조건의 운행횟수 일자 자료가 존재하는 날.

D_m = T_m ∩ F_m. 두 지표의 Main 날짜 모집단은 D_m으로 맞춘다. 한 자료에만 존재하는 날짜도 원본과 존재표에 남기되 Main 지표에는 사용하지 않는다.

N_m = |P_m|, n_time = |T_m|, n_count = |F_m|, n_common = |D_m|를 별도로 저장한다. 실제 존재는 정책유형, 양수시간, 정류장 매칭 필터를 적용하기 전 자료에서 판단한다. 특수행만 존재하거나 정상 행이 전혀 없는 날은 '정상 자료 사용불가'를 추가 표시하고 D_m에는 넣지 않는다. 원본 날짜 존재 플래그 자체는 지우지 않는다. 적은 행 수만으로 새 날짜 제외 임계값을 만들지 않는다.

원자료 전체 부재, 개별 키의 행부재, 시간0, 시간 빈칸, 횟수 빈칸, 명시적 횟수0, 충돌 보류를 독립 상태로 보존한다. 휴일이면서 파일이 없는 날짜는 holiday=True와 source_present=False를 함께 저장한다. 그 날짜는 N_m에 들어가지 않지만 파일 누락 이력은 남는다. 없는 값을 0으로 채우기, 복사, 보간은 금지한다.

## 3. 월 전체 자료커버리지

월의 날짜 적격은 다음을 **모두** 충족해야 한다.

1. n_common ≥ ceil(0.90 × N_m).
2. n_common ≥ L_m = max(16, ceil(N_m × 16/19)).
3. 각 주에 n_common_week ≥ min(3, 그 주의 계획 평상 평일 수).
4. 원자료 스키마, 날짜 의미와 단위에서 해결되지 않은 구조적 모순이 없다. 필요한 역사 마스터 근거는 별도 실행조건을 충족한다.

90%는 결측을 허용하되 계획일의 최대 10%까지만 자료 전체 부재를 허용하려는 설계 선택이다. 기존 구간 관측비율 16/19보다 월 전체 입력의 기준을 높여, 많은 날짜가 통째로 빠진 달을 정상 월로 비교하지 않는다. 최적값으로 검증된 숫자가 아니며 85%, 95% 등을 돌려 통과월을 늘리거나 결과를 선택하지 않는다. 100% 요구는 한두 날짜 누락만으로 모든 기간을 버리며, 관측일만 분모로 삼는 방식은 결측을 숨긴다는 한계가 있어 채택하지 않았다.

조건 미달 월은 `month_status=held_insufficient_coverage`로 남기고 Main 지표, 상관 및 후보 반복성 분모에서 보류한다. 자료구조 불명은 `held_structure`, 마스터 근거 미충족은 `held_master`로 구분한다. 새 공식 원본으로 날짜가 복구되면 동일 규칙으로 전체 월을 재판정하고 입력 버전 변경을 기록한다. 기준 자체를 낮추지 않는다. 해당 월에 후보가 0개였다고 코딩하지 않는다.

## 4. 구간과 시간대의 최소 양수일

**최종 선택은 A를 보수적으로 보완한 C: max(16, ceil(N_m × 16/19))일 이상**이다. 분모 N_m은 계획된 평상 평일 수로 고정한다. 실제 사용한 양수값은 D_m 안의 서로 다른 날짜에서만 센다. 키는 노선 ID, 출발 ID, 도착 ID, 출발 순서, 도착 순서, 시간대다. 같은 날 중복은 관측일을 늘리지 않는다.

| 대안 | 판단 |
| --- | --- |
| ceil(N_m × 16/19)만 적용 | 원래 비율을 보존하지만 휴일 많은 달에는 기존 최소보다 적은 15일의 P90을 허용할 수 있음 |
| ceil(n_common × 16/19) + 월 커버리지 | 실현 관측일의 반복성을 보지만 날짜 부재가 많을수록 같은 달의 요구일이 줄어듦 |
| 채택: 계획일 비율 + 16일 하한 | 누락으로 문턱이 낮아지지 않고 기존보다 짧은 표본의 P90을 새로 허용하지 않음 |

16은 모든 달의 고정 기준이 아니라 작은 표본을 막는 안전 하한이다. 19개 계획일에서는 16일, 20개에서는 17일, 22개에서는 19일이 필요하다. 계획일 17개인 달에는 비율만 적용한 15일 대신 16일을 요구한다. 이는 기존 8월 취지를 다개월로 옮길 때 추가한 보수적 설계 결정이며 과거부터 적용한 규칙이라고 쓰지 않는다.

양수시간은 유한하고 숫자로 읽히며 0보다 큰 값이다. 0과 음수, 비숫자, 빈칸 및 값충돌 보류는 양수일에 포함하지 않는다. 일반 양수 극단값은 크기만으로 제거하거나 절단하지 않는다. 2→3 제외는 별도 고정 구조규칙이다.

## 5. 주별 분포조건

월요일~일요일의 달력 주를 월 경계에서 자른다. W_mw = P_m 중 해당 주에 속한 날짜, p_mw = |W_mw|. 각 구간×시간대의 해당 주 양수 관측일은 **min(3, p_mw)일 이상**이어야 한다. p_mw=0이면 조건을 부과하지 않는다. 이 조건을 모든 부분주와 휴일 포함 주에도 적용한다.

| 계획 평상 평일 p_mw | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 필요한 양수일 | 0 | 1 | 2 | 3 | 3 | 3 |

완전주에만 3일 조건을 적용하면 월초나 월말의 관측 단절을 놓칠 수 있다. ceil(3/5 × p_mw)는 3일짜리 주에서 2일을 허용해 가능한 3일 반복조건을 완화한다. 채택안은 가능한 한 기존 3일을 유지하고, 달력상 불가능한 1~2일짜리 부분주만 전일 관측으로 대체한다. 자료가 빠져도 p_mw를 줄이지 않는다. 1일짜리 부분주의 그 하루가 없으면 월 또는 해당 조합이 보류될 수 있는 보수적 비용을 수용한다.

기존 8월 4주 설계의 주별 계획일 5,5,4,5에는 그대로 3,3,3,3일을 요구한다. 월간 조건과 주간 조건은 동시 적용하며 서로 대체하지 않는다.

## 6. 18일 강건성의 일반화

18이라는 절대일수를 복사하지 않고 L_strict = max(16, ceil(N_m × 18/19))로 동결한다. 주별 조건은 Main과 동일하다. 해당 월 D_m이 이 일수에 못 미치면 엄격 표본 강건성은 '계산 불가'로 기록하며 실패율이나 후보0으로 바꾸지 않는다. Main 적격 월을 강건성 불가 때문에 자동 삭제하지 않는다. 지표의 명칭은 '18/19 비율의 엄격 관측조건'으로 쓴다.
